## 📊 Example: Mean, Variance, and Standard Deviation

The NumPy practice program calculates statistical measurements from a numerical dataset.

Example dataset:

```python
import numpy as np

X = np.array([5, 7, 9, 11, 13])

print("Mean:", np.mean(X))
print("Variance:", np.var(X))
print("Standard Deviation:", round(np.std(X), 2))
```

Output:

```text
Mean: 9.0
Variance: 8.0
Standard Deviation: 2.83
```
